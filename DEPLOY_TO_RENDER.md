# 🚀 KidZone — Deploy to Render (Free Tier)

A complete, step-by-step guide to deploy this Django project on [Render](https://render.com) for **free**.

---

## Prerequisites

Before deploying, make sure you have:

- [ ] A **GitHub** account with this project pushed to a repository
- [ ] A **Render** account (free at render.com)
- [ ] A **Cloudinary** account (free at cloudinary.com) — for image storage
- [ ] *(Optional)* A Gmail account for sending emails

---

## Step 1 — Push to GitHub

```bash
# If not already a git repo, initialize it
git init
git add .
git commit -m "chore: configure for Render deployment"

# Push to GitHub
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
git branch -M main
git push -u origin main
```

---

## Step 2 — Get Your Cloudinary URL

1. Go to [cloudinary.com](https://cloudinary.com) → Sign up (free)
2. After login, go to **Dashboard**
3. Copy the **API Environment variable** — it looks like:
   ```
   cloudinary://123456789012345:your-api-secret@your-cloud-name
   ```
4. Save this — you'll need it in Step 4.

---

## Step 3 — Deploy on Render

### Option A — Blueprint (Recommended, Automatic)

1. Go to [render.com](https://render.com) → **New** → **Blueprint**
2. Connect your GitHub account and select your repository
3. Render will automatically detect `render.yaml` and create:
   - ✅ A **Python Web Service** (your Django app)
   - ✅ A **PostgreSQL Database** (free tier)
4. Click **Apply** — Render will start the first build

### Option B — Manual Setup

1. Go to [render.com](https://render.com) → **New** → **Web Service**
2. Connect your GitHub repo
3. Fill in:
   - **Runtime**: Python
   - **Build Command**: `./build_files.sh`
   - **Start Command**: `gunicorn myproject.wsgi:application --workers 2 --timeout 120 --bind 0.0.0.0:$PORT`
   - **Plan**: Free

Then create a database:
1. **New** → **PostgreSQL**
2. **Plan**: Free
3. After creation, copy the **Internal Database URL**

---

## Step 4 — Set Environment Variables

In your Render Web Service → **Environment** tab, add these:

| Variable | Value |
|---|---|
| `DEBUG` | `False` |
| `CLOUDINARY_URL` | Your Cloudinary URL from Step 2 |
| `ALLOWED_HOSTS` | `your-app-name.onrender.com` |
| `CSRF_TRUSTED_ORIGINS` | `https://your-app-name.onrender.com` |
| `DATABASE_URL` | Auto-linked if using Blueprint, or paste Internal DB URL |
| `STRIPE_PUBLISHABLE_KEY` | Your Stripe key (or keep placeholder for now) |
| `STRIPE_SECRET_KEY` | Your Stripe secret |
| `STRIPE_WEBHOOK_SECRET` | Your Stripe webhook secret |
| `EMAIL_HOST_USER` | Your Gmail address |
| `EMAIL_HOST_PASSWORD` | Your Gmail App Password |

> ⚠️ `SECRET_KEY` is auto-generated by the Blueprint. If setting manually, generate a strong key at:
> https://djecrety.ir/

---

## Step 5 — Wait for Build

After setting env vars, Render will auto-deploy. Watch the logs:
- ✅ `Installing dependencies...`
- ✅ `Collecting static files...`
- ✅ `Running database migrations...`
- ✅ `Build complete!`
- ✅ `Listening on 0.0.0.0:10000`

Your app will be live at: `https://your-app-name.onrender.com`

---

## Step 6 — Set Up Django Admin & Site

### Create Superuser
In Render → your web service → **Shell** tab:
```bash
python manage.py createsuperuser
```

### Fix Django Site (Required for Google OAuth)
1. Go to `https://your-app-name.onrender.com/admin/`
2. Login with your superuser
3. Go to **Sites** → Click the existing site
4. Change both:
   - **Domain name**: `your-app-name.onrender.com`
   - **Display name**: `KidZone`
5. Save

---

## Step 7 — Update Google OAuth (If Using Google Login)

1. Go to [Google Cloud Console](https://console.cloud.google.com/)
2. Select your project → **APIs & Services** → **Credentials**
3. Click your OAuth 2.0 Client ID
4. Under **Authorized redirect URIs**, add:
   ```
   https://your-app-name.onrender.com/accounts/google/callback/
   ```
5. Save

Then in Django Admin → **Social Applications** → update your Google app's site to your new Render domain.

---

## Step 8 — Update Stripe Webhook (If Using Stripe)

1. Go to [Stripe Dashboard](https://dashboard.stripe.com/) → **Webhooks**
2. Add endpoint: `https://your-app-name.onrender.com/payment/webhook/`
3. Copy the new **webhook signing secret** and update `STRIPE_WEBHOOK_SECRET` in Render

## ⚠️ Free Tier Limitations

| Limitation | Details |
|---|---|
| **Spin-down** | App sleeps after 15 min inactivity, ~30s wake-up |
| **PostgreSQL expiry** | Free DB expires after 90 days |
| **No persistent disk** | Media files MUST use Cloudinary |
| **750 hrs/month** | ~31 days — enough for 1 service running 24/7 |

## 🔁 Subsequent Deploys

Every `git push` to your main branch will trigger an automatic redeploy on Render.

```bash
git add .
git commit -m "your changes"
git push origin main
# Render auto-deploys!
```

## 🛠️ Troubleshooting

| Problem | Solution |
|---|---|
| `DISALLOWED_HOST` error | Add your Render URL to `ALLOWED_HOSTS` env var |
| `CSRF verification failed` | Add `https://your-app.onrender.com` to `CSRF_TRUSTED_ORIGINS` |
| Images not loading | Check `CLOUDINARY_URL` is set correctly |
| Migration errors | Check Render logs, run `python manage.py migrate` from Shell tab |
| 500 errors | Set `DEBUG=True` temporarily to see errors, then set back to `False` |
